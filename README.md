# Guess My Number!

A simple number-guessing game built with HTML, CSS, and JavaScript.

## 🎮 How to Play

- The computer generates a secret number between **1 and 20**.
- Enter your guess in the input field.
- Click the **Check** button or press **Enter** to submit your guess.
- If your guess is too high, you'll see a message telling you so.
- If your guess is too low, you'll see a message telling you so.
- Guess the correct number to win the game!
- Click **Again** to restart the game with a new secret number.

## ✨ Features

- Random secret number generation.
- Interactive guessing system.
- Score tracking.
- Feedback for incorrect guesses.
- Visual changes when the player wins.
- Ability to restart the game.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation and Event Listeners)

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start guessing!
